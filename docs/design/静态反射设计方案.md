# C^ 静态反射设计方案

> 目标：语言级别的静态反射，零运行时开销，离开标准库也能使用。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **编译期完成** | 所有反射操作在编译期求值，运行时只保留展开后的代码 |
| **语言内置** | 反射是编译器特性，不依赖 `std.meta` 或任何标准库 |
| **零成本** | 反射信息不生成运行时数据结构，元对象在编译期被解析为字面量 |
| **类型安全** | 所有反射操作在语义分析阶段验证，类型错误在编译期报出 |

## 2. 核心语法

### 2.1 `typeof(expr)` — 类型推导

```c^
var x = 42;
var t: Type = typeof(x);  // t 的编译期类型是 int
```

`typeof` 在编译期求值，返回表达式的类型。可以嵌套使用：

```c^
var t = typeof(typeof(x));  // Type of Type — 元类型
```

### 2.2 `@Type` — 类型元对象

```c^
@int          // → 编译期元对象，描述 int 类型
@MyStruct     // → 编译期元对象，描述 MyStruct 类型
@typeof(x)    // → 等价于 @TypeOf(x) 所表示的类型
```

`@` 是前缀一元运算符，优先级最高（高于 `.` 成员访问）。

#### 元对象属性

```
@T.name           → literalview   // 类型名，如 "MyStruct"
@T.size           → int           // 字节大小
@T.align          → int           // 对齐
@T.is_primitive   → bool          // 是否原始类型
@T.is_struct      → bool          // 是否结构体
@T.is_class       → bool          // 是否类
@T.is_enum        → bool          // 是否枚举
@T.is_pointer     → bool          // 是否指针
@T.is_slice       → bool          // 是否切片
@T.field_count    → int           // 字段数量
@T.method_count   → int           // 方法数量
@T.fields         → FieldInfo[]   // 字段元对象数组（编译期）
@T.methods        → MethodInfo[]  // 方法元对象数组（编译期）
```

### 2.3 `T is kind` — 类型特征检查

```c^
if (T is struct) { ... }
if (T is class) { ... }
if (T is integer) { ... }
if (T is pointer) { ... }
```

`is` 是中缀二元运算符，返回 `bool`，仅在编译期求值。

支持的 kind：
- `struct`, `class`, `enum`, `interface`
- `integer`, `float`, `bool`, `char`, `string`
- `pointer`, `reference`, `slice`, `array`, `tuple`
- `function`, `nullable`

### 2.4 `comptime for` — 编译期循环展开

```c^
comptime for (var i = 0; i < @MyStruct.field_count; i++) {
    var f = @MyStruct.fields[i];
    // 编译期展开：i=0 时处理 fields[0]，i=1 时处理 fields[1]，...
}
```

`comptime for` 在编译期完全展开循环体，每次迭代绑定不同的元对象值。

### 2.5 `comptime if` — 编译期条件

```c^
comptime if (@T.is_struct) {
    // 仅当 T 是 struct 时编译此块
}
```

### 2.6 `obj.[field]` — 元对象字段访问

```c^
var f = @MyStruct.fields[0];
var val = obj.[f];  // 编译期字段访问，等价于 obj.field_name
```

## 3. 元对象类型定义

这些类型由编译器内置，不需要用户定义：

```c^
// 编译器内置，用户代码中直接可用
struct FieldInfo {
    name: literalview;
    type: Type;
    offset: int;
    is_public: bool;
    is_mutable: bool;
}

struct MethodInfo {
    name: literalview;
    return_type: Type;
    param_count: int;
    is_public: bool;
    is_static: bool;
    is_virtual: bool;
}

struct TypeInfo {
    name: literalview;
    size: int;
    align: int;
    is_struct: bool;
    is_class: bool;
    is_enum: bool;
    is_primitive: bool;
    field_count: int;
    method_count: int;
}
```

## 4. 实现分层

```
┌─────────────────────────────────────────┐
│              用户代码                     │
│   @MyStruct.fields[0].name              │
│   comptime for (f in @T.fields) { ... } │
├─────────────────────────────────────────┤
│           编译器前端                      │
│   ① 解析: @ → ReflectionExpr            │
│   ② 语义: 收集类型元数据, 展开 comptime   │
├─────────────────────────────────────────┤
│           编译器后端                      │
│   ③ 代码生成: 元对象 → 字面量常量         │
│      @T.name → "MyStruct"               │
│      @T.size → 16                       │
│      @T.fields[0].name → "x"            │
└─────────────────────────────────────────┘
```

### 3.1 元数据收集（语义分析阶段）

当编译器遇到 `struct`/`class`/`enum` 声明时：

```
对每个字段记录：
  - name: 字段名
  - type: 字段的 Type 指针
  - offset: 在结构体中的字节偏移
  - access: public/private/protected

对每个方法记录：
  - name: 方法名
  - return_type: 返回类型
  - params: 参数列表
  - access: 访问修饰符
```

这些数据存储在编译器的 `TypeMetadata` 映射中（`typeName → Metadata`），不在运行时生成。

### 3.2 反射表达式求值（语义分析阶段）

```
@MyStruct
  → 查找 MyStruct 的 TypeMetadata
  → 返回类型为 TypeInfo 的编译期值

@MyStruct.name
  → 解析 @MyStruct 得到 TypeInfo
  → 访问 .name 属性
  → 返回 StringLiteral("MyStruct")

@MyStruct.fields[0]
  → 展开为 FieldInfo 的编译期值
  → .name → StringLiteral("x")
  → .type → @int
  → .offset → IntLiteral(0)
```

### 3.3 comptime 展开（语义分析阶段）

```
comptime for (var i = 0; i < @T.field_count; i++) {
    var f = @T.fields[i];
    process(f);
}

→ 编译期展开为：

{
    var f = @T.fields[0];  // field_count == 3 时
    process(f);
}
{
    var f = @T.fields[1];
    process(f);
}
{
    var f = @T.fields[2];
    process(f);
}
```

## 5. 示例

### 5.1 自动序列化

```c^
struct Point {
    public int x;
    public int y;
}

func serialize<T>(instance: T) -> string {
    var result = "{";
    comptime for (var i = 0; i < @T.field_count; i++) {
        var f = @T.fields[i];
        if (i > 0) result += ", ";
        result += f.name + ": " + to_string(instance.[f]);
    }
    result += "}";
    return result;
}

// 调用：serialize(Point(1, 2))
// 编译期展开：
// {
//     var result = "{";
//     var f = @Point.fields[0]; // f.name = "x"
//     result += "x: " + to_string(instance.[f]);
//     f = @Point.fields[1];     // f.name = "y"
//     result += ", y: " + to_string(instance.[f]);
//     result += "}";
//     return result;
// }
```

### 5.2 类型分发

```c^
func process<T>(value: T) {
    comptime if (T is integer) {
        // 整数处理
        handle_int(value);
    } comptime else if (T is struct) {
        // 结构体处理
        handle_struct(value);
    } comptime else {
        // 其他类型
        handle_generic(value);
    }
}
```

### 5.3 依赖注入

```c^
struct Database {
    public string url;
    public int pool_size;
}

// 编译期自动构建
func autoInject<T>() -> T {
    var instance: T;
    comptime for (var i = 0; i < @T.field_count; i++) {
        var f = @T.fields[i];
        comptime if (f.type is string) {
            instance.[f] = "default";
        } comptime else if (f.type is int) {
            instance.[f] = 0;
        }
    }
    return instance;
}
```

## 8. 与 operator overloading 的关系

操作符重载可以与反射配合：

```c^
struct Vec2 {
    public float x;
    public float y;
}

// 操作符重载
operator+(a: Vec2, b: Vec2) -> Vec2 {
    return Vec2(a.x + b.x, a.y + b.y);
}

// 反射可以查询操作符是否存在
comptime if (has_method(@T, "operator+")) {
    // T 支持加法
}
```

操作符重载是独立特性，不依赖反射，但可以与反射协作。
