## 3. v1 核心范围

v1 稳定范围建议只包含：

### 语言核心
- 基础类型
- 变量、函数、控制流
- 固定数组 / 切片 / 元组
- 指针 / 引用 / `late`
- struct / class / 单继承 / 接口（语法与语义）
- 泛型函数 / 泛型 struct / 基础 concept
- `try/catch/throw` + `defer`
- 模块导入 / `extern "C"` 基础调用

### 编译器/运行时
- SemanticModel + TypeLowering
- 编译器运行时 `libc_hat_rt`
- 基础异常展开与 cleanup
- 基础分配器钩子

### 标准库
标准库最后做，最小范围：

- `std.core`
- `std.mem`
- `std.string`
- `std.text`
- `std.io`

- 虚表 / 虚方法动态派发

- 自动析构 / 完整 RAII 展开
- 多实现继承
- `self~` / 移动语义
- 反射 / `Fold` / `Expansion`
- 协程 `await/yield`
- comptime 执行
- 字符串插值

这些可以保留语法/parser 入口，但必须标记 experimental，不能进入稳定文档。

## 5. 必须先冻结的决策

### 5.1 类型
- SemanticModel 是唯一类型来源
- TypeLowering 是唯一 LLVM 类型降低入口
- 禁止 codegen 猜类型 / 默认 int32

### 5.2 内存
- `defer` 块级
- 非 `late` 局部变量必须初始化
- `late` 检查是变量级，不做逐元素/跨过程分析
- `out T&` 是跨函数初始化契约；`out T!&` 非法
- 栈上/late RAII
- 堆内存显式 `new/delete`
- `new T[n]` 元素生命周期

### 5.3 数组/切片/元组
- 固定数组是值类型
- 固定数组只有整体初始化/整体赋值才算初始化
- 大数组使用 `[value; N]` 批量初始化
- `out int[N]&` 初始化整个数组；`int[]` 普通参数只是视图
- 切片是视图
- `.len = long`
- `..` 半开，`..=` 闭区间
- 元组 literal struct
- 枚举名义类型

### 5.4 OOP
- `self` / `base`
- 单继承 + 多接口
- 默认静态派发，`virtual` 开启动态派发
- vtable / interface fat pointer
- 属性 / static / 构造 / 析构

### 5.5 错误处理
- `T?` / `Result<T, E>` / 异常三层
- 异常任意类型
- catch 基类/接口匹配
- 异常展开执行 defer + 析构

### 5.6 模块/ABI
- 模块可独立编译
- 稳定 mangling
- `extern "C"` C ABI
- 运行时与标准库分离
- 标准库可替换/可缺失
