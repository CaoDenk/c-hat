## 1. 背景

C^ 明确区分数组、切片、指针、引用，但当前实现里仍存在表示不一致：

- 数组字面量在语义上是 `ArrayType`，运行时却用切片 `{ptr, len}` 表示；
- 无初始化器的固定数组用 LLVM 数组表示；
- `new T[n]` 返回切片；
- `.len` 目前是 `int`，长度上限不足；
- 切片区间和 `foreach` 范围的区间语义不一致；
- 元组是 literal struct，但命名元组、比较、整体赋值未定义。

需要冻结数组/切片/元组的值语义和 ABI。

---

## 2. 决策

### 2.1 固定数组是值类型

- `T[N]` 是固定长度数组，值类型。
- LLVM 表示为 `[N x T]`。
- 数组赋值是逐元素复制。
- 数组作为函数参数/返回值时按值传递/返回。
- 数组的 `.len` 是编译期常量，类型为 `long`。
- 数组的 `.ptr` 返回指向首元素的指针：
  - `T[N]` -> `T^`
  - `T![N]` -> `T!^`

### 2.2 切片是视图

- `T[]` 是非拥有切片视图，LLVM 表示为 `{T*, long len}`。
- `T![]` 是只读切片视图，底层表示相同，只读性由 semantic 检查。
- 切片赋值是浅拷贝：复制 `{ptr, len}`，不复制元素。
- 切片不拥有内存；生命周期由创建者/借用规则约束。
- `.len` 类型为 `long`。
- `.ptr` 返回：
  - `T[]` -> `T^`
  - `T![]` -> `T!^`

### 2.3 数组字面量

- `var a = [1, 2, 3]` 推断为 `int[3]` 固定数组值。
- `int[3] a = [1, 2, 3]` 是固定数组值。
- `int[] s = [1, 2, 3]` 创建 backing array + 切片视图。
- backing array 的生命周期延长到当前作用域；切片不能逃逸到生命周期之外。
- 数组字面量不隐式变成堆分配。
- 空数组 `[]` 需要显式类型或上下文类型。

### 2.4 数组到切片

- `T[N] -> T[]` 合法，产生指向数组首元素的切片视图。
- `T[N] -> T![]` 合法，产生只读视图。
- `T[] -> T![]` 合法。
- `T![] -> T[]` 非法。
- 切片不能隐式转回固定数组；需要显式复制/构造。
- 数组到切片的生命周期：切片不得比 backing array 活得更久。

### 2.5 索引与切片区间

- `a[i]` 返回元素引用/左值。
- 索引接受整数类型，内部统一按 `long` 计算。
- 默认启用运行时边界检查；后续可提供显式 unchecked API。
- `a[start..end]` 是半开区间 `[start, end)`，返回切片视图。
- `a[start..=end]` 是闭区间 `[start, end]`，返回切片视图。
- 切片不分配新数组。
- `foreach (i : a..b)` 与 `a[a..b]` 统一使用半开区间。
- `foreach (i : a..=b)` 使用闭区间。

### 2.6 `new T[n]`

- `new T[n]` 返回 owning slice `T[]`。
- 长度为 `long`。
- 对非平凡类型逐元素构造；构造失败时逆序析构已构造元素。
- `delete slice` 释放底层数组；`delete[]` 作为兼容/底层形式保留。
- 切片拷贝不转移所有权；创建者负责释放一次。
- 空指针 delete 为 no-op。
- v1 不引入 `owned T[]` 类型；所有权通过文档/约定表达，后续可引入显式 owner 类型。

### 2.7 元组

- 元组是值类型。
- LLVM 表示为 literal struct。
- 支持 `t[N]` 编译期下标。
- 支持解构 `var (a, b) = tuple`。
- 支持作为函数参数/返回值。
- 元组布局由元素类型顺序决定，ABI 稳定。
- v1 不支持命名元组字段访问。
- v1 不支持元组比较/整体赋值；后续可加。
- 空元组不支持；单元素元组不支持。

### 2.8 枚举

- 枚举是名义类型，不是 `int` 的别名。
- 底层用整数表示，具体宽度由声明或默认 `int` 决定。
- 枚举成员访问：`Color.Green` / `Color::Green`（canonical 用 `Color.Green`）。
- 枚举不能隐式转 `int`；需要显式转换。
- `match` 对枚举做穷尽性检查（后续实现）。
- 枚举与整数比较需要显式转换或同类型比较。

### 2.9 只读视图

- `T![]` 是只读切片视图。
- `T!^` 是只读指针。
- `literalview` 是编译器内建的非拥有字节视图。
- `literalview` 可以转 `byte!^` / `byte![]`。
- `literalview` 不能转可写 `byte^` / `byte[]`。
- 只读只能“加”，不能“去”。

### 2.10 ABI

- 固定数组：`[N x T]`
- 切片：`{T*, long len}`
- 元组：literal struct
- 枚举：底层整数
- `literalview`：`{byte!^ ptr, long len}`
- 数组/切片/元组的 ABI 在标准库冻结前固定。
- 跨模块传递切片时，长度使用 `long`，指针按目标平台 ABI。

### 2.11 已确认补充决策

1. **数组字面量默认固定数组。**
   - `var a = [1,2,3]` 推断为 `int[3]`。
   - `int[] s = [1,2,3]` 创建 backing array + 切片。

2. **切片长度统一为 `long`。**
   - 切片内部为 `{T*, long len}`。
   - `.len` 返回 `long`。

3. **数组到切片的生命周期检查。**
   - 切片不得比 backing array 活得更久。
   - 返回局部数组的切片是错误。
   - 返回切片参数或堆数组切片是合法的。
   - v1 先做局部逃逸检查，完整生命周期分析后续增强。

4. **默认启用边界检查。**
   - 索引和切片默认检查边界。
   - 后续可提供显式 unchecked API。

5. **`new T[n]` 返回 owning slice。**
   - 长度为 `long`。
   - 非平凡类型逐元素构造/析构。

6. **`delete slice` 为 canonical。**
   - `delete` 接受指针和 owning slice。
   - `delete[]` 兼容保留。
   - 空指针 no-op。

7. **元组 v1 不支持命名元组。**
   - 支持 `t[N]`、解构、参数/返回。
   - 命名元组、元组比较、整体赋值后续实现。

8. **枚举禁止隐式转 `int`。**
   - 枚举是名义类型。
   - 需要显式转换。
   - `match` 穷尽性后续实现。

9. **固定数组按整体值初始化。**
   - `late T[N]` 只有整体初始化/整体赋值才算初始化。
   - 元素写入不改变整个数组的初始化状态。
   - 不做逐元素 definite assignment。

10. **大数组使用 `[value; N]` 批量初始化。**
    - `N` 是编译期常量；v1 实现先支持整数字面量。
    - 全零/字节模式可 lowering 为 `memset`。
    - v1 支持标量、POD、固定数组。

11. **跨函数初始化使用 `out T&`。**
    - `out int[N]&` 初始化整个固定数组。
    - `out int[]&` 只初始化切片描述符，不保证 backing array 元素已初始化。
    - `int[]` 普通参数只是视图，不是初始化。
    - `out T!&` 非法。

### 2.12 `let` 与数组字面量

```c^
let a = [1, 2, 3];   // int[3]

a = [4, 5, 6];       // Error：不能重新绑定
a[0] = 9;            // OK：元素仍可修改
```

- `let` 只表示绑定不可重新赋值。
- 不表示数组元素只读。
- 数组字面量仍按上下文推导：无显式类型时默认 `int[3]`。
- 元素只读使用 `int![3]` / `int![]`。
- 编译期常量/只读数据使用 `const int[3]`。
- `let int[] s = [1,2,3]`：绑定不可变，切片元素可写，backing array 必须可写。
- `let int![] r = [1,2,3]`：绑定不可变，元素只读，backing array 可放 `.rodata`。

### 2.13 backing array 术语与生命周期

**backing array** 是切片实际指向的连续数组存储。切片本身只是 `{ptr, long len}` 视图，不拥有元素。

```c^
int[] s = [1, 2, 3];
```

等价于：

```text
backing array: [1][2][3]
                  ^
s:             {ptr, 3}
```

规则：

- 切片赋值只复制 `{ptr, len}`，不复制 backing array。
- 通过切片修改元素，修改的是 backing array。
- 数组转切片 `int[] s = a;` 中，`a` 就是 backing array。
- `a[start..end]` 返回指向 backing array 内部的子切片，不创建新数组。
- `new T[n]` 的 backing array 在堆上。
- 字面量切片的 backing array 由上下文决定：
  - 可写切片：backing array 必须可写（栈或堆）。
  - 只读切片：backing array 可以放 `.rodata`。
- `int[]` 是可写切片，不能指向 `.rodata`。
- `int![]` 是只读切片，可以指向 `.rodata`。
- 切片不能比 backing array 活得更久。
- 返回局部数组的切片是错误；返回只读字面量切片可以放到静态存储。
- `delete` owning slice 释放的是 backing array。

### 2.14 数组初始化、`late` 与 `out T&`

固定数组是整体值：

```c^
int[5] a = [1, 2, 3, 4, 5];  // 声明时整体初始化
late int[5] b;
b = [0; 5];                 // 整体赋值后才可读
b[0] = 7;                   // 之后可修改元素
```

不允许把逐元素写入当作整体初始化：

```c^
late int[5] b;
b[0] = 1;
b[1] = 2;
return b[0];                // Error：整个 b 仍未初始化
```

大数组批量初始化：

```c^
int[10000] zero = [0; 10000];
int[256] ones   = [1; 256];
```

跨函数初始化：

```c^
func fill(out int[10000]& dst) {
    dst = [0; 10000];
    dst[0] = 7;
}

func main() -> int {
    late int[10000] a;
    fill(&a);
    return a[0];
}
```

规则：

- `out T&` 是初始化引用，不是值参数；不会值拷贝数组。
- `out int[N]&` 负责整个固定数组初始化。
- `out int[]&` 只初始化 `{ptr, len}`，不保证 backing array 元素已初始化。
- `int[]` 普通参数只是视图，不能用于初始化 backing array。
- `s = arr` 保留数组 backing array 别名，不复制元素。
- `out int[]&` 初始化切片描述符；backing array 生命周期仍由调用方保证。
- `out T!&` 非法：初始化必须写入。
- 调用方只在正常返回后认为数组已初始化；异常路径不标记。
- v1 的 `out` 先限制为标量、固定数组、POD struct。

## 3. 备选方案

### 方案 A：数组字面量默认切片

优点：实现简单，和当前代码接近。
缺点：固定数组和切片身份混乱，数组值语义丢失。

结论：不选。

### 方案 B：数组字面量默认固定数组（推荐）

优点：数组/切片身份清晰，值语义一致。
缺点：需要 backing array 生命周期延长和切片逃逸检查。

结论：选 B。

### 方案 C：切片拥有内存

优点：API 简单。
缺点：切片变成 owning 类型，和“视图”语义冲突。

结论：不选；owning slice 后续用显式 owner 类型表达。

1. 数组字面量默认固定数组。
2. 切片长度统一为 `long`。
3. 切片不得比 backing array 活得更久；v1 做局部逃逸检查。

6. `new T[n]` 返回 owning slice。
7. `delete slice` 为 canonical；`delete[]` 兼容保留。
8. 元组 v1 不支持命名元组。
9. 元组 v1 不支持比较/整体赋值。
10. 枚举禁止隐式转 `int`。

12. 大数组使用 `[value; N]` 批量初始化。
13. 跨函数初始化使用 `out T&`；`out T!&` 非法。
